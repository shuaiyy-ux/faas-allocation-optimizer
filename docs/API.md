# API Contract

This document summarizes the REST API surface for future backend and integration
work. The canonical machine-readable contract is generated by FastAPI:

- Swagger UI: `/docs`
- ReDoc: `/redoc`
- OpenAPI JSON: `/openapi.json`

All session-scoped endpoints require an `X-Session-Id` header. The frontend
generates one UUID per browser tab and sends it on every API call. Confirm and
Reset mutate only that session's in-memory fleet snapshot; they do not write
CSV files or call external systems.

## Session Header

```http
X-Session-Id: 47d8e1f4-ef27-4d4c-8f8d-4b2c8b8a9c8a
```

If a session-scoped endpoint is called without this header, the server returns
`400` with a missing-session error.

## Endpoints

| Method | Path | Session | Purpose |
|---|---|---:|---|
| `GET` | `/` | No | Serves the dashboard HTML. |
| `GET` | `/api/defaults` | No | Returns canonical scoring defaults from `engine.DEFAULT_*`. |
| `GET` | `/api/sessions` | Yes | Session-scoped diagnostic view for the current session. |
| `GET` | `/api/overview` | Yes | Returns session-scoped dealer network overview. |
| `GET` | `/api/fleet` | Yes | Returns session-scoped fleet inventory. Confirmed vehicles appear as `Transporting`. |
| `POST` | `/api/allocate` | Yes | Runs full-fleet allocation and caches the result in the session. |
| `POST` | `/api/weekly` | Yes | Runs weekly ILP allocation for a selected batch or VIN list. |
| `POST` | `/api/weekly_greedy` | Yes | Runs the weekly Greedy baseline for comparison. |
| `POST` | `/api/confirm` | Yes | Applies assignments to the current session snapshot and clears allocation cache. |
| `POST` | `/api/reset` | Yes | Restores the current session snapshot from the immutable baseline. |
| `GET` | `/api/home` | Yes | Returns Home dashboard payload plus fleet-wide watchlist cache. |
| `POST` | `/api/watchlist/refresh` | Yes | Refreshes fleet-wide watchlist alerts. |
| `GET` | `/api/allocation_cache` | Yes | Returns cached allocation result, optionally filtered by VIN or dealer. |
| `GET` | `/api/export/confirmed` | Yes | Future export hook for confirmed assignments. Stub only. |
| `POST` | `/api/approve_constraint` | Yes | Mints a one-shot token for approved MCP mutation tools. |
| `GET` | `/api/chat_status` | Yes | Returns current session chat quota. |
| `POST` | `/api/chat` | Yes | Streams chat agent events with Server-Sent Events. |
| Any | `/mcp/*` | URL scoped | FastMCP streamable HTTP transport for the Claude CLI agent's tools. Requires the internal `X-Internal-Key` header (403 otherwise). |

## Allocation Request Shape

`POST /api/allocate`, `POST /api/weekly`, and `POST /api/weekly_greedy` accept
the calibrated scoring fields documented in OpenAPI:

- `w_util`, `w_rented`, `w_dist`, `w_tax`
- `miles_per_util`, `dollars_per_util`
- `source_limit`
- `expected_stay_months`
- `scoring_mode`, either `additive` or `bucket`
- `bucket_mults`, `bucket_signal_field`

`POST /api/weekly` and `POST /api/weekly_greedy` also accept `n_batch`, `seed`,
and `vin_list`.

The solver response has mode-specific dynamic fields. OpenAPI documents the
stable wrapper and the detailed runtime shape is available from the generated
schema and the current endpoint response.

## Confirm Flow

`POST /api/confirm` accepts:

```json
{
  "assignments": [
    {
      "vin": "VIN_XXXXXXXXXX001",
      "dealer_code": "FD01",
      "dealer_name": "FaaS_Dealer_Alpha"
    }
  ]
}
```

The response is:

```json
{
  "updated": 1,
  "skipped": 0,
  "total": 1
}
```

Confirm changes only rows that are currently `Grounded`. Confirmed vehicles
become `Transporting`, receive `ASSIGNED_DEALER`, and appear in `GET /api/fleet`.
The allocation cache is cleared after confirm, so `GET /api/allocation_cache`
is not a post-confirm export source.

## Future Confirmed Export Hook

`GET /api/export/confirmed` is a backend adapter placeholder for future external
handoff work. It returns confirmed vehicles from the current session in JSON:

```json
{
  "status": "stub",
  "integration_status": "not_connected",
  "format": "json",
  "count": 1,
  "vehicles": [
    {
      "vin": "VIN_XXXXXXXXXX001",
      "status": "Transporting",
      "assigned_dealer": "FD01",
      "assigned_dealer_name": "FaaS_Dealer_Alpha",
      "assigned_state": "CA",
      "source": "D001",
      "source_city": "Los Angeles",
      "source_state": "CA",
      "residual": 22500.0,
      "week": "2025-12-15",
      "distance": 228.5
    }
  ],
  "note": "Future export adapter only. This endpoint reads the current session snapshot and does not persist data or call external systems."
}
```

This endpoint does not write CSV files, does not persist allocation history, and
does not run automatically after `/api/confirm`.

## Contract Testing

Focused pytest coverage checks endpoint behavior and OpenAPI generation:

```bash
.venv/bin/python -m pytest app/tests/test_server_contracts.py -q
```

Optional external contract fuzzing can target the generated schema once the
server is running:

```bash
schemathesis run http://localhost:8000/openapi.json
```

Schemathesis is not a runtime dependency of the app.
